# Contributing

1. Fork the repository and create a focused branch.
2. Use semantic HTML, responsive CSS and readable JavaScript.
3. Test changes using [TESTING.md](TESTING.md).
4. Open a pull request with a summary and test notes.

Do not commit credentials, payment information or personal data. Keep controls accessible and document security assumptions for backend changes.

Ideas: wishlist, price filter, pagination, reviews, product detail pages, automated tests and backend integration.
